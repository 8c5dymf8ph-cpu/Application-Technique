# Maquettes

Six écrans mobiles (390 × 844) publiés sur un canevas :
https://claude.ai/artifact/Qa89iyADqTh6eRQ55xzyN2

| Fichier | Écran |
|---|---|
| `Main.dc.html` | Accueil — indicateurs et accès Technique / Gouvernante |
| `Declaration.dc.html` | Déclaration d'anomalie : chambre puis recherche au catalogue |
| `Technicien.dc.html` | Tournée : anomalies groupées par chambre, fin d'intervention |
| `Gouvernante.dc.html` | Validation : bloc technicien, décision en trois issues |
| `Bouteilles.dc.html` | Parc Purezza en quatre positions et déclaration d'incident |
| `Produit.dc.html` | Fiche produit : d'où vient le stock, mouvements, devis |

Les chiffres et les libellés viennent de l'export réel de « TEST Tech 3 ».

Pour modifier : éditer les `.dc.html`, puis regénérer le canevas et le republier
(l'assistant s'en charge — les fichiers sources sont ici pour que rien ne se perde).
